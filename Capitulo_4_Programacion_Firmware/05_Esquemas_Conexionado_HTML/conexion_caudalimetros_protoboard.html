⚠️
Regla de Oro de Seguridad Eléctrica:
Alimentar siempre el cable rojo de los caudalímetros a 3.3V (pin 3V3) y NUNCA a 5V. De este modo, la señal cuadrada de pulsos generada por el sensor Hall oscila entre 0V y 3.3V, protegiendo las entradas GPIO del ESP32 contra sobretensiones destructivas.
💻 Código de Lectura con Interrupciones (C++)

El conteo se realiza por hardware mediante interrupciones en flanco de subida (RISING), garantizando cero pérdida de pulsos durante el giro de la bomba NEMA 34.

// Pines de caudalímetros const uint8_t PIN_CAUDAL_PERMEADO = 27; // GPIO 27 const uint8_t PIN_CAUDAL_RETENTADO = 14; // GPIO 14 volatile unsigned long pulsosPermeado = 0; volatile unsigned long pulsosRetentado = 0; // Rutinas de servicio de interrupción (ISR en IRAM) void IRAM_ATTR isrPermeado() { pulsosPermeado++; } void IRAM_ATTR isrRetentado() { pulsosRetentado++; } void setup() { pinMode(PIN_CAUDAL_PERMEADO, INPUT_PULLUP); pinMode(PIN_CAUDAL_RETENTADO, INPUT_PULLUP); attachInterrupt(digitalPinToInterrupt(PIN_CAUDAL_PERMEADO), isrPermeado, RISING); attachInterrupt(digitalPinToInterrupt(PIN_CAUDAL_RETENTADO), isrRetentado, RISING); } // Cálculo de Caudal instantáneo: Q (L/min) = (Pulsos / 98) * (60 / dt) float calcularCaudalLMin(unsigned long pulsos, float deltaSegundos) { return (pulsos / 98.0) * (60.0 / deltaSegundos); }
