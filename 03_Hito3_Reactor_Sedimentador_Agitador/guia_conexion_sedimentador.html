Acople Mecánico: ¿Cómo conectar este motor con la paleta y la tapa?

⚠️ EL RETO MECÁNICO DEL TORNILLO SINFÍN BLANCO

Tu motor tiene en su punta un tornillo sinfín (engranaje helicoidal plástico blanco). Un tornillo sinfín está diseñado para empujar una rueda dentada perpendicular, no para acoplarse directamente a una varilla axial. Para unirlo a tu turbina de 6 álabes tienes dos caminos mecánicos:

MÉTODO DIRECTO (Recomendado si no tienes caja reductora)

1. Extraer el Sinfín y Usar Acople de Aluminio

1. Extracción del sinfín plástico: Coloca la punta plástica durante 30 segundos en agua caliente o aplícale aire caliente con secador de pelo/pistola de calor para dilatar el plástico y retíralo suavemente con un alicate o extractor de piñones, cuidando de no doblar el eje de acero de 2 mm.
2. Acople de Aluminio 2 mm a M6/M8: Una vez libre el eje metálico de 2 mm, colocas un acople rígido o flexible con prisioneros Allen (como los de impresoras 3D/CNC). El lado de 2 mm aprieta el eje del motor; el lado de 6 u 8 mm rosca el vástago de la paleta.

PASO POR LA TAPA METÁLICA

2. Fijación Rígida y Buje en la Tapa

1. Buje Guía en el Orificio Excéntrico: En el agujero de tu tapa (foto TAPA SEDIMENTADOR.jpeg), coloca un buje pasante de teflón o bronce o un rodamiento con retén para que el eje largo de la paleta gire centrado y no roce metal contra metal.
2. Soporte / Puente en U para el Motor: El cuerpo metálico del motor debe atornillarse rígidamente a la tapa con una brida o abrazadera metálica. El motor no debe colgar únicamente del eje.

Conexión Eléctrica: Identificación de Bornes en tu Driver L298N

Borneras de Potencia y Motor

Borneras Azules del L298N

  • Borne +12V Positivo de Fuente 12V DC (Externa)
  • Borne GND Masa Común (GND Fuente + GND ESP32)
  • Borne +5V Sin conectar (o salida auxiliar)
  • Borne OUT1 Cable 1 del Motor 12V
  • Borne OUT2 Cable 2 del Motor 12V
Pines de Control hacia el ESP32 (Hito 3)

Tira de Pines Macho (Control Lógico)

  • Pin ENA (PWM) ESP32 GPIO 4 *(Quitar jumper negro)*
  • Pin IN1 (Sentido A) ESP32 GPIO 16
  • Pin IN2 (Sentido B) ESP32 GPIO 17
  • Jumper 5V Enable PUESTO (Habilita regulador 78M05 interno)
  • IN3, IN4, ENB Libres (Canal B no utilizado)

Alineación con los Hitos de la Planta de Ultrafiltración

Para que tu conexión no rompa ninguno de los otros hitos ya implementados en el repositorio:

Hito 1 (Bomba Peristáltica NEMA 34)

Convivencia con la Bomba MBP-2000

La bomba peristáltica utiliza el canal LEDC 0 en `GPIO 18` (PUL) y `GPIO 19` (DIR). El agitador usa el canal LEDC 1 en `GPIO 4`. Ambos pueden operar en paralelo sin conflicto gracias al procesador Dual-Core del ESP32.

Hito 3 & 4 (Enclavamientos de Seguridad)

Enclavamiento por Boya Inox (`GPIO 32`)

La boya de acero inoxidable va conectada entre `GPIO 32` y `GND` (con `INPUT_PULLUP`). Si el nivel de agua en el sedimentador desciende por debajo de 4 cm sobre el cono, el circuito se abre y el ESP32 **apaga automáticamente el motor de la paleta y la bomba**.

Código Firmware ESP32 (Arduino C++) para Hito 3

control_motor_12v_sedimentador.ino 
// ==============================================================================
// PLANTA PILOTO DE ULTRAFILTRACIÓN FX100 - HITO 3: CONTROL AGITADOR 12V
// Hardware: ESP32 + Driver L298N (HW-095) + Motor 12V + Boya Inoxidable
// ==============================================================================

// PINES ASIGNADOS SEGÚN EL REPOSITORIO PLANTA-ULTRAFILTRACION
const int PIN_MOTOR_PWM = 4;   // ENA del Driver L298N (Quitar jumper negro)
const int PIN_MOTOR_IN1 = 16;  // IN1 Dirección de giro A
const int PIN_MOTOR_IN2 = 17;  // IN2 Dirección de giro B
const int PIN_BOYA_NIVEL = 32; // Boya de seguridad en tanque sedimentador

// CONFIGURACIÓN PWM LEDC ESP32
const int PWM_CANAL      = 1;     // Canal 1 (Canal 0 reservado para NEMA 34)
const int PWM_FRECUENCIA = 1000;  // 1 kHz
const int PWM_RESOLUCION = 8;     // 8 bits (0 a 255)

// VALORES PWM PARA CICLO JAR TEST (GRADIENTE DE CAMP-STEIN)
const int PWM_MEZCLA_RAPIDA = 200; // ~150 RPM (Coagulación rápida, 60s)
const int PWM_MEZCLA_LENTA  = 85;  // ~30 RPM (Floculación lenta, 15 min)

void detenerMotor() {
  ledcWrite(PWM_CANAL, 0);
  digitalWrite(PIN_MOTOR_IN1, LOW);
  digitalWrite(PIN_MOTOR_IN2, LOW);
}

void girarMotor(int pwmVelocidad, bool sentidoHorario = true) {
  if (sentidoHorario) {
    digitalWrite(PIN_MOTOR_IN1, HIGH);
    digitalWrite(PIN_MOTOR_IN2, LOW);
  } else {
    digitalWrite(PIN_MOTOR_IN1, LOW);
    digitalWrite(PIN_MOTOR_IN2, HIGH);
  }
  ledcWrite(PWM_CANAL, pwmVelocidad);
}

void setup() {
  Serial.begin(115200);
  delay(1000);
  Serial.println("\n--- PLANTA PILOTO UF: CONTROL MOTOR 12V & L298N INICIADO ---");

  pinMode(PIN_MOTOR_IN1, OUTPUT);
  pinMode(PIN_MOTOR_IN2, OUTPUT);
  pinMode(PIN_BOYA_NIVEL, INPUT_PULLUP);

  // Configuración del periférico LEDC
  ledcSetup(PWM_CANAL, PWM_FRECUENCIA, PWM_RESOLUCION);
  ledcAttachPin(PIN_MOTOR_PWM, PWM_CANAL);

  detenerMotor();
  Serial.println("Agitador en reposo. Envíe 'START' para iniciar ciclo de agitación.");
}

void loop() {
  // 1. CHEQUEO OBLIGATORIO DE BOYA DE SEGURIDAD (MARCHA EN SECO)
  // LOW = Hay líquido; HIGH = Tanque vacío (contacto abierto)
  if (digitalRead(PIN_BOYA_NIVEL) == HIGH) {
    detenerMotor();
    Serial.println("🚨 ALARMA: Nivel bajo en sedimentador. Motor detenido por seguridad.");
    delay(500);
    return;
  }

  // 2. COMANDOS POR MONITOR SERIE / DASHBOARD SCADA
  if (Serial.available()) {
    String cmd = Serial.readStringUntil('\n');
    cmd.trim();

    if (cmd.equalsIgnoreCase("START")) {
      Serial.println("Iniciando Rampa Suave -> Mezcla Rápida (Coagulación)...");
      // Rampa suave para no sobrecargar el eje ni el acople
      for (int v = 0; v <= PWM_MEZCLA_RAPIDA; v += 10) {
        girarMotor(v);
        delay(30);
      }
      delay(5000); // Demostración

      Serial.println("Cambiando a Mezcla Lenta (Floculación)...");
      girarMotor(PWM_MEZCLA_LENTA);
      delay(5000); // Demostración

      Serial.println("Deteniendo agitador para fase de sedimentación...");
      detenerMotor();
    } else if (cmd.equalsIgnoreCase("STOP")) {
      detenerMotor();
      Serial.println("Motor apagado.");
    }
  }
}
